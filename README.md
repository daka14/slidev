# Captor — Slidev-presentation

Presentation om [Captor Fund Management AB](https://www.captor.se), byggd från offentligt material på deras webbplats.

## Starta

```bash
npm install
npm run dev
```

Öppna adressen som terminalen visar (vanligtvis `http://localhost:3030`).

## Övriga kommandon

| Kommando | Vad det gör |
| --- | --- |
| `npm run dev` | Utvecklingsserver med live-reload |
| `npm run build` | Statisk export till `dist/` |
| `npm run export` | Export till PDF (kräver Playwright) |

Källmaterial: [captor.se](https://www.captor.se), fondöversikt, Asterstrategin, om oss, hållbarhet och legal information.
